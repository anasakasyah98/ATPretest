◆ wait_for_at_ready()

wait_for_at_ready ( serial_port,
timeout )

Wait until the modem answers "AT" on an open port.

Some modems (e.g. QCX216) drop everything sent during roughly the first second after the port is opened, so "AT" is repeated until "OK" arrives.

Parameters
[in]serial_portOpen serial port
[in]timeoutMaximum wait in seconds
Returns
(True, response) once "OK" was received, otherwise (False, response)
